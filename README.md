# claude-code-session-meter

A [Claude Code](https://claude.com/claude-code) mod that shows how much of your session budget you have used, at the bottom right of the prompt footer:

```
ctx ▓░░░ 23% │ 5h ░░░░ 12% 3h10m │ 7d ▓░░░ 34% │ $0.457
```

| Segment | Meaning |
|---|---|
| `ctx` | How full the context window is |
| `5h` | Usage of the 5-hour rate-limit window, with a countdown to its reset |
| `7d` | Usage of the weekly rate-limit window |
| `$` | Session cost in USD |

Each bar has 4 cells, filled in quarters. The bar and its percentage turn **green** up to 60%, **yellow** up to 80% and **red** above that. Labels, countdown and cost stay plain. Segments that Claude Code doesn't report (for example rate limits on API-key billing) are left out.

The 5-hour countdown ticks every minute, including between turns.

## Install

1. Clone the repo:

   ```sh
   git clone https://github.com/cpolito88/claude-code-session-meter.git ~/.claude/mods/session-meter
   ```

2. Point Claude Code at it in `~/.claude/settings.json`:

   ```json
   {
     "env": {
       "CLAUDE_CODE_PLUGIN_DIRS": "~/.claude/mods/session-meter"
     }
   }
   ```

3. Restart Claude Code.

## How it works

`hooks/register.tsx` registers three hooks:

- `session.start` reads the first usage figures and starts a one-minute timer for the countdown.
- `session.measure` saves fresh context, rate-limit and cost figures to the plugin's state on every measurement.
- `ui.render` on the `SessionMode` footer component draws the meter, after any other active mode labels.

## Development

The Claude Code type definitions (`.claude-plugin/types/claude-code*`) are generated by Claude Code and not committed. Once Claude Code has loaded the mod, type-check with:

```sh
npx tsc -p .
```

Tests live in `tests/meter.test.tsx` and use the `claude-code/testing` harness.
